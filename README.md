# வீட்டு முறை சமையல் — React Website

A simple mobile-first React + Vite homepage for the homemade-food business.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Update business details

Open `src/App.jsx` and update:

- `BUSINESS_NAME`
- `LOCATION`
- `PHONE_1`
- `PHONE_2`
- `WHATSAPP_1`
- `WHATSAPP_2`
- `MAPS_LINK`

## Deploy

This project is ready for GitHub + Vercel.

1. Create a GitHub repository.
2. Upload/push this project.
3. Import the repository into Vercel.
4. Vercel will detect Vite automatically.
5. Deploy.

No backend or database is required for this version.
